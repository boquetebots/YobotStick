  NOTHING GETS INSTALLED.

  Python, and everything else Yobot needs, is already on this drive.
  Nothing is copied to your computer, nothing is added to Windows,
  nothing is left behind. Unplug the drive and your PC is exactly as
  it was.

  That also means you do not need to be an administrator, and for most
  of it you do not need the internet.


---------------------------------------------------------------------------
  WHAT IS ON THIS DRIVE
---------------------------------------------------------------------------

  Four things to click, and a folder of extras:

      TEST THIS COMPUTER.bat   Run this FIRST on any new computer.
      START YOBOT.bat          Opens Yobot's control page in your browser.
      STOP YOBOT.bat           Stops everything, however it was started.

      Utilities\               The show, chess, and the version number.

  The folders called OhbotPi2, Chess and python are the machinery. You
  never need to open them, and they have to stay where they are.


---------------------------------------------------------------------------
  START HERE
---------------------------------------------------------------------------

  1. Double-click   TEST THIS COMPUTER.bat

     A minute or so. It checks this machine can run Yobot and whether
     it can see the robot, and it says so in plain words.

  2. Double-click   START YOBOT.bat

     A black window opens, then your browser. That web page is the
     control panel - every button is on it.

  3. When you have finished, double-click   STOP YOBOT.bat

  LEAVE THE BLACK WINDOW OPEN while Yobot is running. It is not an
  error message, it is the engine. Closing it stops the robot.

  Yobot waits until it is properly awake before opening your browser,
  so the page should be ready when it appears. The first run on a new
  computer takes longer - that is Python waking up off the drive - and
  it is quicker after that.


---------------------------------------------------------------------------
  PLUGGING THE ROBOT IN
---------------------------------------------------------------------------

  The robot connects by USB. Plug it in BEFORE you start Yobot. If you
  plug it in afterwards, stop and start again so it gets noticed.

  You can run Yobot with no robot attached. The control page works;
  there is just nothing to move.

  THE FIRST TIME, WINDOWS FIREWALL WILL ASK. Click "Allow access".
  Yobot is not reaching out to the internet there - it is opening a
  page for your own browser, on your own machine. Refuse, and the page
  will not load.


---------------------------------------------------------------------------
  IN THE UTILITIES FOLDER
---------------------------------------------------------------------------

  YOBOT SHOW.bat            The pre-recorded show. Voice and all.
                            NO INTERNET AND NO ACCOUNTS NEEDED.

  GET THE CHESS ENGINE.bat  Run once, with internet, if you want chess.
  PLAY A HUMAN CHESS.bat    You against the robot.
  ROBOT v ROBOT CHESS.bat   Two robots against each other.

                            you ask anyone for help.

  THE SHOW IS THE ONE TO TRUST in a hall where the wifi cannot be
  relied on. It plays from recordings already on this drive, so it
  needs nothing at all from the outside world.


---------------------------------------------------------------------------
  WHAT NEEDS AN ACCOUNT
---------------------------------------------------------------------------

  For Yobot to LISTEN and to SPEAK ITS OWN WORDS, rather than play
  recordings, it needs a Microsoft Azure account. Light use costs
  pennies. It is the only account Yobot cannot do without.

  For Yobot to HOLD A CONVERSATION, it needs one AI account as well -
  any of OpenAI, Anthropic, Google Gemini or Groq. Or Ollama running
  on your own computer, which needs no account at all.

  YOU DO NOT HAVE TO EDIT ANY FILE. Start Yobot, and on the page that
  opens click "Settings & Keys". Paste your keys in there and it will
  test each one and tell you whether it works.

  There are no keys on this drive when it arrives. When you add yours
  they are saved ONTO THE DRIVE - so you only do it once, and so does
  anyone you lend the drive to. Worth remembering before you hand it
  over.

  Yobot will tell you when something is missing rather than starting
  and failing quietly. Chess will not open without its engine, and the
  conversation bot will not start without a voice key.


---------------------------------------------------------------------------
  CHESS
---------------------------------------------------------------------------

  All three files are in Utilities. Run them in this order:

  1. GET THE CHESS ENGINE.bat - once, with the internet connected.

     The engine is a separate 109 MB program called Stockfish, with its
     own licence, so it is fetched from its makers rather than carried
     here. After this one run, chess works offline too.

  2. PLAY A HUMAN CHESS.bat   - a person plays the robot.
  3. ROBOT v ROBOT CHESS.bat  - two robots play each other.

  The board and the game need no accounts. Only the robot's
  commentary does, and that is the Azure key above.


---------------------------------------------------------------------------
  THREE WINDOWS TRAPS WORTH KNOWING ABOUT
---------------------------------------------------------------------------

  UNZIPPING TAKES A FEW MINUTES, and looks like it has stopped. There
  are several thousand small files here - most of them tiny pieces of
  Python - and Windows checks every one on the way past. It is slow on
  a fast computer and slower on an old one.

  Let it finish. A half-extracted copy looks perfectly fine and then
  fails later in ways nobody can work out. The same goes for deleting
  it again afterwards, if you ever do.

  IF YOU DOWNLOADED THIS AS A ZIP: Windows lets you look inside a ZIP
  as though it were an ordinary folder. Yobot half-works from in
  there, in ways that waste an afternoon. Right-click the ZIP, choose
  "Extract All", and copy the real folder's contents onto the drive.

  WINDOWS MAY WARN YOU about running a file it downloaded - "Windows
  protected your PC". Click "More info", then "Run anyway". If it
  still refuses, right-click the file, Properties, and tick "Unblock"
  at the bottom.


---------------------------------------------------------------------------
  MOVING IT OFF THE DRIVE
---------------------------------------------------------------------------

  You can copy everything here onto a hard disk and it will still
  work. Nothing remembers a drive letter, so E: becoming F: on the
  next machine breaks nothing.

  Keep the folders together. python, OhbotPi2 and Chess must stay
  beside each other, because that is how they find one another.


---------------------------------------------------------------------------
  A NEWER VERSION
---------------------------------------------------------------------------

  There is no update button in this version. Download the new ZIP,
  extract it, and copy the contents over this drive.

  Keep your own things: if you added keys, copy OhbotPi2\.env across
  afterwards. Your robot's calibration and any sequences you made are
  in OhbotPi2\ohbotData and OhbotPi2\sequences.


---------------------------------------------------------------------------
  WHEN SOMETHING IS WRONG
---------------------------------------------------------------------------

  RUN TEST THIS COMPUTER.bat AGAIN. It is written to explain what it
  finds rather than just pass or fail, and it catches most of it.

  Nothing changed after an update?
      The browser is showing you a saved copy of the page. Hold Ctrl
      and press F5.

  It greets you, then goes quiet?
      It is listening to the wrong microphone. A laptop usually has
      two or three and Windows does not always pick the one you mean.
      The Settings page lets you choose.

  Chess says something is missing?
      Run GET THE CHESS ENGINE.bat in Utilities, with the internet on.

  Windows blocked a file?
      Right-click it, Properties, tick "Unblock" at the bottom, OK.

  When you ask anyone for help, open Utilities\VERSION.txt and quote
  it. It says precisely which build you have, which turns guesswork
  into an answer.
