# ===========================================================================
#  stick-manifest.txt  -  EXACTLY what a Yobot stick contains
# ===========================================================================
#
#  This is an ALLOW LIST, taken from the working stick at
#  D:\Projects\YobotStick on 2026-09-19. build-stick.bat deletes anything in
#  the three pruned folders below that is not named here, and REFUSES TO
#  BUILD if anything named here is missing.
#
#  WHY THIS FILE EXISTS
#  --------------------
#  The first build used the robot repo's own export-ignore rules instead.
#  That was wrong, and not obviously wrong, which is the dangerous kind.
#  export-ignore trims the GENERAL GitHub download - the one that has to
#  serve Mac, Pi and Windows people at once. A Windows-only stick needs a
#  narrower list. The v1.0 ZIP built that way carried Mac\, Raspberry Pi\,
#  yobot_mac.py, install.sh, three .command files and four Pi shell scripts
#  onto a Windows stick, and left OUT voice_cache, without which the offline
#  show has no voice at all.
#
#  So: reuse a list only after checking what it was written for.
#
#  HOW TO CHANGE IT
#  ----------------
#  Add a line to add a file to the stick. Delete a line to drop one. A folder
#  named here is taken whole - only the three folders marked [prune] below are
#  filtered at all; everything else comes across complete.
#
#  If the robot project gains a genuinely new Windows file, the build will
#  quietly leave it out until it is added here. That is the trade for having
#  Mac and Pi files drop out on their own. The build prints every file it
#  drops, so a surprise shows up in the log rather than on a stranger's laptop.
#
#  Paths are relative to the top of the stick, and use backslashes.
#
# ===========================================================================
